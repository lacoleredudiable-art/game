# 2B.5b — PrototypeTuning bölüm nesneleri (A5 adım 1)

## Ne değişti

- `PrototypeTuning` alanları yedi `[Serializable]` bölümde: `Arena`, `Boss`, `Camera`, `Hud`, `Input`, `Player`, `Visuals` (`Game/Config/Sections/*Settings.cs`).
- Eski düz Unity anahtarları `PrototypeTuning.Legacy.cs` içinde `[SerializeField, HideInInspector]` olarak kalır; `OnAfterDeserialize` ile `SectionsVersion < 1` iken bölümlere kopyalanır.
- `tuning.json` yalnız `PanelFields` DTO'sunu yazar — JSON şekli değişmedi.

## Sahne göçü (executor / editör)

1. Bu sürümü al.
2. Unity: **Dovus → Tuning → Migrate scene tuning to sections**  
   veya batchmode: `-executeMethod Dovus.Game.Editor.TuningSectionsMigration.MigrateFromCommandLine`
3. `Assets/Scenes/Prototype.unity` kaydedilir (bölüm YAML + legacy düz anahtarlar birlikte).

**Not:** Başka dalda `Prototype.unity` tuning değerlerini değiştirdiysen, o dalı merge etmeden önce bu sürümde göç aracını çalıştır; aksi halde düz anahtarlar bölümlere taşınmadan kalabilir.

## Runtime

- Okuma/yazma: `tuning.Camera.CameraDistanceM` vb.
- SweepV2 sahne YAML okuması legacy alanlara yazar, ardından `SyncSectionsFromLegacyFlatFields()` çağrılır.
